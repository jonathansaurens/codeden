- **Connected agents.** Owners can add an agent in Settings › Members › Add agent: a name, Viewer or Operator (never Owner), optional per-project roles, and a token shown once. Tokens are stored hashed, can be revoked or replaced, and show when they were last used. An agent may answer approvals only when an owner turns on **May answer approvals** for it; questions it can always answer.
