- **Seeing machines at work.** A session on a machine shows the machine's name and state in its header, Settings › Machines shows each machine's live capacity (cores, CPU busy, free memory) and lets you set its preference (and Home's), and a session whose machine can't be reached gets an inbox item saying which machine and why. Sessions on machines and in sandboxes always use the streamed browser view.
