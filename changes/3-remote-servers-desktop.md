- **Open other CodeDen servers in the desktop app.** Add a server on your tailnet (`https://<machine>.<tailnet>.ts.net:8446`) from **Servers › Add server...** and it opens in its own window with its own sign-in, next to **This Mac**, which works as before. A chip in the sidebar header and **Servers** (Cmd/Ctrl+1 to 9) switch between windows. Notifications name the server, the dock badge adds up what waits on you everywhere, and the tray lists each server with its counts. Remote windows can't use the native folder picker or the native session browser. See [Other CodeDen servers](docs/desktop.md#other-codeden-servers).
